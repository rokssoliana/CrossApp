\# CrossApp



Наскрізний навчальний проєкт з дисципліни «Крос-платформне програмування».



\## Предметна область: Склад

\- \*\*Сутності:\*\* Product (товар), StockBatch (партія), Warehouse (склад), Movement (переміщення)

\- \*\*Призначення:\*\* облік залишків товарів за партіями та складами

## Лабораторна робота 4: Доменні інваріанти сутності Product
1. **Ідентифікація**: `Id`, `Sku`, `Name` не можуть бути порожніми або складатись лише з пробілів (`ArgumentException`).
2. **Невід'ємний залишок при створенні**: початкова кількість товару не може бути `< 0` (`ArgumentOutOfRangeException`).
3. **Валідні операції приходу та видачі**: кількість надходження або списання має бути суворо `> 0` (`ArgumentOutOfRangeException`).
4. **Запобігання перевитраті (дефіциту)**: кількість видачі товару не може перевищувати поточний залишок на складі (`InvalidOperationException`).

## Лабораторна робота 6: Доменні події та делегати
- Оголошено подію `Changed` типу `EventHandler<CatalogChangedEventArgs>` у `CatalogService`.
- Шар `Core` не використовує `Console` та не має залежностей від файлової системи для логування.
- У `Cli` реалізовано двох підписників: локальний метод (вивід у консоль і запис у `logs/app.log`) та лямбда із замиканням над лічильником подій.
- Продемонстровано роботу оператора відписки `-=`.
- Реалізовано метод `FindAll` із використанням делегата `Func<Product, bool>`.
